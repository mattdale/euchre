# 🃏 Euchre 

A sleek, browser-based Euchre game built as a fun side project for fans of the classic trick-taking card game. 

This project aims to provide a fast, responsive, and beautiful Euchre experience directly in your web browser. Whether you're a seasoned player from the Midwest or just learning the ropes, this web app offers an intuitive interface and AI opponents to practice with.

## ✨ Features
- **Play Anywhere:** Fully responsive design that plays great on both desktop monitors and mobile devices.
- **Custom Aesthetics:** Features high-fidelity custom SVG suit icons, crisp layout animations, and modern UI elements.
- **Smart AI Opponents:** Play alongside and against computer-controlled players that understand the nuances of Euchre strategy (including a tough "Intense" difficulty mode!).
- **Classic Rules:** Supports all the classic mechanics: Stick the Dealer, Going Alone, and standard trump bidding phases.
- **No Dependencies:** Built with pure vanilla HTML, CSS, and JavaScript. No build steps or heavy frameworks required!

## 🚀 How to Run
Since it's built with vanilla web technologies, you don't need any complex setup to get started:

1. Clone or download the repository to your local machine.
2. Simply open `index.html` in your favorite modern web browser.
3. *Optional:* Use a simple local server (like VS Code Live Server or python's `http.server`) if you want to avoid local file restrictions.

## 🛠️ Built With
- **HTML5 & CSS3:** Utilizing CSS Grid, Flexbox, and complex CSS masking/drop-shadow tricks for dynamic graphic rendering.
- **Vanilla JavaScript:** All game logic, AI decision-making, and DOM manipulation are handled natively without external libraries.
